Soul Snatched: Ginger Edition

2D top-down village defense ARPG - soul-siphoning, morality, and wave-based survival.

Overview

Soul Snatched: Ginger Edition is a 2D top-down action RPG where a lone ginger defends villages from nightly zombie invasions. By day, you prepare defenses, upgrade gear, and manage relationships. By night, you survive waves, siphon souls, and walk the line between protector and monster.

Core Systems Implemented

  • Day/Night loop controlling village recovery, crafting, and zombie invasions.
  • Wave-based enemy spawning with difficulty scaling and multi-lane routing.
  • Morality and reputation system tied to soul-siphoning villagers.
  • Hair-as-magic visual indicator that tracks your soul power and sanity.
  • Vendor and shop UI with reputation-based inventory and item quality.
  • Equipment and stats system driving player power and survivability.
  • Event-driven audio and UI feedback for combat, waves, and upgrades.
  • Data-driven item & vendor pipeline: external Node.js/React dashboard exports JSON (items, stats, rarities, vendors, vendor stock) that Unity imports at runtime.

Tools & Pipeline

Beyond the game client, Soul Snatched includes a full tooling stack: a Node.js/Express backend and React dashboard used to author items, enchantments, and vendor inventories. The tools export clean JSON which is consumed by Unity importers to rebuild ItemDef ScriptableObjects and vendor stock automatically, keeping design and implementation in sync without manual data entry.

Echoes of Genesis

Systems & narrative design case study, large-scale class design, encounter structure, and world architecture.

Overview

Echoes of Genesis is a long-form game design project exploring MMO-scale systems: specialization-driven classes, scalable combat frameworks, and narrative delivered as a gameplay system. This page showcases design artifacts and production-ready concepts (not a gameplay build).

Design Pillars

  • Systems-first architecture built for expansion.
  • Strong class identity through specialization and resource mechanics.
  • Encounters designed for coordination, readability, and role clarity.
  • Narrative delivered through diegetic UI and in-world artifacts (CABAL / archives), not exposition dumps.

Design case study highlights

  • Specialization-driven class framework with role clarity.
  • Encounter design built for telegraphs, coordination, and readability.
  • Diegetic UI concept (security-desk login) used for lore delivery.

Highlighted Systems

  • Class & specialization framework: role clarity, tradeoffs, and modular growth.
  • Resource/alignment mechanics: Void/Light/Twilight/Cosmos themes influencing ability behavior.
  • Encounter design: multi-phase fights built around teamwork and movement.
  • Diegetic UI concepts: security-desk login experience and foreshadowing systems.
